## APP-001 · Нова информационна архитектура

Главни раздели Преглед, Регистър, Анализи, Наблюдение; акаунтът и помощта са отделно; неподготвено не се представя като работещо.

- **Приоритет / етап / вълна:** P1 / R2 / 6
- **Резултат:** navigation config
- **Зависимости:** ARC-006, UX-002
- **Основание:** WL-04, LIVE-11 · покрива: LIVE-11, WL-04
- **Статус:** planned

**Приемане**

- Производители/търговци са роли във Фирми
- Няма два празни основни таба за интерес към бъдеща функция

**Конкретна проверка:** Намери продукт, фирма, промени и план с ясен маршрут.

## APP-002 · Полезен обзор

Покажи кратки KPI с мерна единица, период, freshness и връзки към точния филтър; едно място за системния source status.

- **Приоритет / етап / вълна:** P1 / R2 / 11
- **Резултат:** overview screen
- **Зависимости:** APP-001, UX-010, API-011
- **Основание:** OV-06, OV-07, LIVE-01 · покрива: LIVE-01, OV-06, OV-07
- **Статус:** planned

**Приемане**

- Статусът различава checked/downloaded/published/source date
- Клик на KPI отваря същия набор и count

**Конкретна проверка:** Последен неуспешен import при стар, но валиден активен набор.

## APP-003 · Работен екран Регистрации

Една активна търсачка, основни/разширени филтри, chips, table/cards и ясно поле за дата; запази контекста.

- **Приоритет / етап / вълна:** P1 / R2 / 20
- **Резултат:** registration list screen
- **Зависимости:** UX-009, API-004, API-005
- **Основание:** PR-03, PR-08 · покрива: PR-03, PR-08
- **Статус:** planned

**Приемане**

- Търсачките не поддържат различни заявки
- Изчистване премахва всички активни скрити филтри

**Конкретна проверка:** Отвори от фирмен профил, добави дата и изчисти фирмения chip.

## APP-004 · Пълен детайл на регистрация

Секции идентичност, фирми, състав, дати, предназначение/съхранение, история и източник; drawer е preview на същия модел.

- **Приоритет / етап / вълна:** P1 / R2 / 21
- **Резултат:** registration detail screen
- **Зависимости:** API-006, UX-003, UX-008, ING-012
- **Основание:** PR-13, PR-14, LIVE-05 · покрива: LIVE-05, PR-13, PR-14
- **Статус:** planned

**Приемане**

- Показани са всички налични полезни полета и uncertainties
- Назад връща същия scroll/filter context

**Конкретна проверка:** От списък на page 3 отвори детайл и се върни.

## APP-005 · Общ каталог на фирми

Ролеви филтри производител/търговец/двете; държава с evidence; една идентичност и общи sort/export контроли.

- **Приоритет / етап / вълна:** P1 / R2 / 20
- **Резултат:** company list screen
- **Зависимости:** APP-001, ENT-012, UX-009
- **Основание:** CO-07 · покрива: CO-07
- **Статус:** planned

**Приемане**

- Промяна на роля не сменя идентичността на фирмата
- Totals съвпадат със server query

**Конкретна проверка:** Една фирма с две роли се отваря към един canonical profile.

- **Зависимости:** APP-005, ENT-012, UX-003
- **Основание:** CO-08, LIVE-15 · покрива: LIVE-15, CO-08
- **Статус:** planned

- **Основание:** LIVE-06, LIVE-09 · покрива: LIVE-06, LIVE-09

- **Основание:** DESIGN · покрива: DESIGN
