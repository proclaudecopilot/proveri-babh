## XLS-001 · Инвентар на реалните формати

Раздели XLSX/XLS/CSV/PDF само ако са реално срещнати; документирай поддържаните варианти и explicit unsupported.

- **Приоритет / етап / вълна:** P0 / R1 / 4
- **Резултат:** format support matrix
- **Зависимости:** ARC-002, ARC-005
- **Основание:** IM-06 · покрива: IM-06
- **Статус:** planned

**Приемане**

- Разширението не определя самостоятелно формата
- Неподдържан формат води до контролирана грешка

**Конкретна проверка:** XLS файл, преименуван на XLSX, не се обработва като ZIP.

## XLS-002 · Избор на лист и схема по съдържание

Чети workbook relationships; откривай header signature и версии на schema; не избирай най-големия лист.

- **Приоритет / етап / вълна:** P0 / R1 / 5
- **Резултат:** sheet detector и schema registry
- **Зависимости:** XLS-001
- **Основание:** IM-06 · покрива: IM-06
- **Статус:** planned

**Приемане**

- Помощен голям лист не се приема за регистър
- Разместени колони се map-ват по проверени заглавия

**Конкретна проверка:** Workbook с cover sheet, два data sheets и разменени колони.

## XLS-003 · Пълно четене на текстови клетки

Поддържай shared strings, inline strings, rich text runs и Unicode; пази raw content и normalized text отделно.

- **Приоритет / етап / вълна:** P0 / R1 / 6
- **Резултат:** cell decoder
- **Зависимости:** XLS-002
- **Основание:** IM-07 · покрива: IM-07
- **Статус:** planned

**Приемане**

- Всички rich text сегменти се запазват
- Не се губят кирилица, NBSP и нови редове

**Конкретна проверка:** Състав в shared string с множество rich text runs.

## XLS-004 · Координати, празни и слети клетки

Използвай cell references при sparse rows; forward fill само в изрично разрешени merged header/record правила.

- **Приоритет / етап / вълна:** P0 / R1 / 7
- **Резултат:** row assembler
- **Зависимости:** XLS-003
- **Основание:** IM-06 · покрива: IM-06
- **Статус:** planned

**Приемане**

- Празна клетка не измества следващите колони
- Не се пренася фирма от предишна регистрация по предположение

**Конкретна проверка:** Ред без C и със стойност в D; merged header над три колони.

## XLS-005 · Заглавия, бележки и продължаващи редове

Класифицирай повторени headers, footer, празни редове и доказани continuation patterns; пази причината за изключване.

- **Приоритет / етап / вълна:** P0 / R1 / 8
- **Резултат:** row classifier
- **Зависимости:** XLS-004
- **Основание:** IM-06 · покрива: IM-06
- **Статус:** planned

**Приемане**

- Няма тихо изхвърлен некласифициран ред
- Продължение се свързва само при проверено правило

**Конкретна проверка:** Повторено заглавие насред sheet и състав на два реда.

## XLS-006 · Дати в Excel

Обработвай 1900/1904 epoch, number formats и фиктивния serial 60 с изрична политика; запази raw serial.

- **Приоритет / етап / вълна:** P0 / R1 / 7
- **Резултат:** excel date decoder
- **Зависимости:** XLS-003
- **Основание:** IM-07 · покрива: IM-07
- **Статус:** planned

**Приемане**

- Датите са детерминистични и валидни календарно
- Ambiguous или serial 60 се маркира за преглед

**Конкретна проверка:** Еднаква дата в двата epoch и тест около февруари 1900.

## XLS-007 · Числа и формули без изпълнение

Различавай cached formula result от липсващ резултат; не изпълнявай формули, макроси или external links.

- **Приоритет / етап / вълна:** P0 / R1 / 7
- **Резултат:** safe scalar decoder
- **Зависимости:** XLS-003
- **Основание:** IM-07 · покрива: IM-07
- **Статус:** planned

**Приемане**

- Липсващ cached result не става нула
- Водещи нули и scientific notation при идентификатори се пазят/маркират

**Конкретна проверка:** Формула без cache, номер 000123 и числово E notation.

## XLS-008 · Дублирани и конфликтни source редове

Сравни canonical key и сурово съдържание в и между части; identical duplicate има отчет, conflict има quarantine.

- **Приоритет / етап / вълна:** P0 / R1 / 9
- **Резултат:** duplicate classifier
- **Зависимости:** XLS-005
- **Основание:** IM-06 · покрива: IM-06
- **Статус:** planned

**Приемане**

- Няма first wins/last wins без политика
- И двата конфликтни оригинала са достъпни

**Конкретна проверка:** Един номер с различни фирми в две части на снимката.

## XLS-009 · Потоково четене с лимити

Ограничи RAM, compressed/uncompressed sizes, rows, cells и време; shared strings се обработват с bounded storage.

- **Приоритет / етап / вълна:** P0 / R1 / 7
- **Резултат:** stream reader и resource budgets
- **Зависимости:** XLS-003
- **Основание:** IM-08 · покрива: IM-08
- **Статус:** planned

**Приемане**

- Консумацията е измерена с най-големия реален файл и stress fixture
- Няма повторно пълно разархивиране за всяка порция

**Конкретна проверка:** Голям sharedStrings.xml и лист с разредени високи индекси.

## XLS-010 · Различаване на край от повреда

XML/ZIP грешка или truncated stream е fatal за снимката; checkpoint не маскира счупен EOF.

- **Приоритет / етап / вълна:** P0 / R1 / 8
- **Резултат:** reader error model
- **Зависимости:** XLS-009
- **Основание:** IM-09 · покрива: IM-09
- **Статус:** planned

**Приемане**

- Повреден файл никога не достига validated
- Съобщението включва file/sheet/row и безопасна причина

**Конкретна проверка:** Прекъсни XML в последните 5% от файла.

## XLS-011 · Защита на parser от злонамерени файлове

Забрани XXE/external entities, path traversal и zip bombs; ограниченията важат и за админ upload.

- **Приоритет / етап / вълна:** P0 / R1 / 8
- **Резултат:** parser security policy
- **Зависимости:** XLS-009
- **Основание:** DESIGN · покрива: DESIGN
- **Статус:** planned

**Приемане**

- Четенето няма достъп до външна мрежа или системни файлове
- Archive expansion над лимита се прекратява

**Конкретна проверка:** Тестов XXE payload, ../ entry и висок compression ratio.

## XLS-012 · Приемане на workbook reader

Изгради отделен набор от реални и синтетични fixtures с очаквани клетки, редове, причини и hashes.

- **Приоритет / етап / вълна:** P0 / R1 / 10
- **Резултат:** reader golden suite
- **Зависимости:** XLS-006, XLS-007, XLS-008, XLS-010, XLS-011
- **Основание:** DESIGN · покрива: DESIGN
- **Статус:** planned

**Приемане**

- 100% от очакваните клетки и класификации съвпадат
- Нов формат не се допуска без fixture и schema version

**Конкретна проверка:** Изпълни целия corpus два пъти с идентичен резултат.
